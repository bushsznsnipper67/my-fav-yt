# My Favourite YouTuber – AussieAntics 🎮

Welcome to my webpage about my favourite YouTuber, **AussieAntics!**

## 📌 About the Project

This is a simple HTML and CSS website created to share information about my favourite YouTuber, AussieAntics. It includes a picture, information about him, and my favourite video.

## ⭐ Features

* 🎮 Introduction to AussieAntics
* 🖼️ Picture of AussieAntics
* 🎥 Embedded YouTube video
* 📖 About section with information about his Fortnite content
* 🎨 Light blue background and styled headings
* 📱 Responsive webpage setup

## 🛠️ Technologies Used

* **HTML5** – Used to structure the webpage.
* **CSS3** – Used to style the webpage, including colours, fonts, and images.

## 📂 Project Files

```text
My-Favourite-Youtuber/
│
├── index.html
├── style.css
└── aussieantics .jpg
```

### File Descriptions

**index.html**

Contains the main webpage, including the headings, paragraphs, image, and YouTube video.

**style.css**

Contains the styling for the webpage, including the background colour, font sizes, image styling, and video border radius.

**aussieantics .jpg**

The picture of AussieAntics displayed on the webpage.

## 🎥 My Favourite Video

The website features the video:

**Poverty to Millionaire – Fresh's Story**

Watch it on the webpage to learn more about Fresh's story.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Make sure `index.html`, `style.css`, and `aussieantics .jpg` are in the same folder.
3. Open `index.html` in your browser.
4. Enjoy the website!
